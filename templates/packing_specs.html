📐 Packing Specs

The size, weight and item type the courier CSV uses for each Packing Spec. Codes like OB, CS, Pallet and FP carry their size in the code; every other spec (A4 box, P7 jiffy bag…) uses the values saved here. Changes apply to the next preview or Generate. Weights are where each carton starts in the preview, where they can be changed for one job.

Codes with the size in them

The numbers are millimetres: OB1370170170 is 1370 × 170 × 170 mm = 137 × 17 × 17 cm. They can run together or be separated (OB 170 x 170 x 1200). When the digits could be split more than one way, sizes in whole centimetres win (1701701200 → 17 × 17 × 120). Use Check a code below to see how a code is read.
