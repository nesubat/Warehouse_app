  • Store Names: Must be in a single, continuous column. A blank cell tells the engine the store list has ended. Duplicate store names will cause grouping collisions in the Label Shuffler!

  • Data Entry: Use numbers for quantities. Dashes (-) and periods (.) are safely ignored as zero. Words (e.g., "J468791-01 or Banners") will generate unique signature codes.
  • File Type: Only standard .xlsx or .xls files are supported.
