⚠️ Requirements

  • Header Row: Tell the tool which row holds your headers (e.g. 1 or 2). It finds the columns automatically.
  • Required Columns: "Packing Spec", "Job Number" and "Install" must be present.
  • Packing Spec: Merge the Packing Spec cells across all rows that go in the same box. Every row needs a Packing Spec.
  • Job Number: Every row needs one.
  • Install: Y for a box going to an installer; N or blank for a box going to the store. All rows of one box must agree.
  • Address: All rows of one box must have the same address (merged cells are fine). A store's own boxes must share one address; installer boxes may differ.
  • Store / Receiver: The store column can be headed "Store Name", "Retailer", "Receiver Name", "Receiver" or "Consignee". Address columns can be headed with or without "Receiver" / "Store" in front (e.g. "Receiver Address Line 1", "Store Suburb").
  • Whole address in one column: One "Address" column holding everything also works, e.g. Andrew, 27 Sirius Road, Lane Cove NSW, 2067. The parts can be separated by commas, semicolons, |, line breaks, " - " or " / ", or just spaces. The name at the front becomes the receiver (and the label's store name when there's no store column); a person and a company both given become contact and receiver. Phone numbers are ignored.
  • Receiver name only: A file with no address columns still works. Each receiver's address is filled in from the address book when it holds one address for that receiver; otherwise the consignment preview lists its saved addresses to pick from, or you type it in. Boxes still without an address are left out of the courier CSV.
  • Thumbnail: Put each row's image inside its own Thumbnail cell. Several images in one cell, or a merged Thumbnail cell, are all used.
  • Other Columns Supported: "Store Name" (or "Receiver Name"), "Quantity", "Description", "Width" & "Height" (or "Dimension"), "Address Line 1", "Address Line 2", "Suburb", "State", "Postcode", "Country", "Material" and "Notes".
